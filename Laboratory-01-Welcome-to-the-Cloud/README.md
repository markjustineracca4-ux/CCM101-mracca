# Laboratory 01: Welcome to the Cloud

## Mission Overview
Completed the Cloud Engineer Onboarding Challenge using KillerCoda and GitHub.

## Objectives
- Access a cloud-based Linux environment using KillerCoda.
- Explore and navigate the Linux operating system.
- Gather basic system information.
- Organize files and directories using Linux commands.
- Create and maintain a professional GitHub repository.
- Document technical work using Markdown.

## Activities Performed
- Created a new user account with sudo privileges.
- Extracted kernel, CPU, RAM, and disk storage information.
- Constructed workspace directory structure.
- Created GitHub repository and initialized documentation.

## Linux Commands Used
- useradd, passwd, su
- whoami, pwd, hostname
- cat, uname, lscpu, free, df
- mkdir, ls, cp, cd

## Skills Learned
- Linux terminal navigation and user management.
- System hardware and OS diagnostics.
- Technical writing and version control with Git/GitHub.
