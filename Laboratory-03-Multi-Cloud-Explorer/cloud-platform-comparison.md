## Analysis Questions

### 1. Which cloud provider offers the broadest range of services?
Amazon Web Services (AWS) offers the broadest range of cloud services in the market today [1]. As the pioneer of public cloud infrastructure since 2006, AWS boasts over 200 fully featured services ranging from basic compute to niche specialized enterprise tools [1]. This maturity ensures that nearly any infrastructure edge-case can be solved natively on AWS [1].

### 2. Which provider best integrates with Microsoft technologies?
Microsoft Azure provides the most seamless integration for organizations running Microsoft technologies [2]. It natively connects with tools like Active Directory (Microsoft Entra ID), Office 365, and Windows Server environments without friction [2]. Furthermore, features like Azure Hybrid Benefit make it exceptionally cost-effective for existing Microsoft licensees [2].

### 3. Which provider is strongest in Artificial Intelligence and Kubernetes?
Google Cloud Platform (GCP) is the strongest contender in Artificial Intelligence and Kubernetes orchestration [3]. Having originally created Kubernetes internally, GCP offers the most mature managed Kubernetes solution with Google Kubernetes Engine (GKE) [3]. Additionally, its Vertex AI platform and custom Cloud TPUs give it a massive edge in machine learning workloads [3].

### 4. Which cloud platform would you personally choose and why?
I would personally choose **Google Cloud Platform (GCP)** because of its developer-friendly tooling, modern UI, and leadership in containerization and AI/ML technologies [3]. Its native support for Kubernetes (GKE) and high-speed global fiber network make it ideal for modern, cloud-native application deployment and data-driven projects [3].
